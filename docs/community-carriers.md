# Community carrier boards

[Back to the project](../README.md)

This directory links to SXM2 carrier boards shared by their authors, from early designs to boards with bring-up reports. Design files and updates live with each author.

> **Community submissions.** Pigeon Labs has not independently tested or approved these designs. Test status and compatibility claims come from the submitter. Check the board revision, supported modules and test evidence before building or using a design.

## Board directory

There are no listings yet. Each entry will include the design link, author, supported modules and module count, PCIe and NVLink configuration, and reported test status with a link to evidence when available.

## Submit a board

Open the [Community carrier board submission form](https://github.com/pigeon-labs-stack/v100-sxm2-reference/issues/new?template=community-carrier.yml). Use it for your own design or submit with the author's permission.

Include the following:

- **Design and author.** Link to a public project page or design repository. Give the name or handle to credit and, if available, a licence and board revision.
- **Configuration.** State which SXM2 modules and how many the board supports. Describe the PCIe connection and any NVLink wiring. Distinguish intended support from tested configurations.
- **Reported test status.** Say whether the board is a design draft, fabricated, tested for PCIe enumeration, or tested with NVLink traffic. Report what passed and what remains untested. Link to bring-up notes, logs or photos if available.
- **Known limitations.** Include any relevant power, cooling, clock or firmware requirements.

The maintainer checks that the link and listing details are usable before adding an entry. For updates, reply on the original submission with the revised link, board revision or test result.
